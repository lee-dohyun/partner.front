## 1. 이 기능으로 할 수 있는 일

판매할 상품을 직접 등록하고, 법에서 정한 상품 정보를 입력한 뒤 검수를 요청합니다.
검수에서 보완 요청을 받으면 무엇을 고쳐야 하는지 해당 입력칸 옆에서 확인하고 다시 제출합니다.
승인된 상품은 PosSelect 쇼핑몰에 판매 상품으로 노출됩니다.

## 2. 시작하기 전에

- **계정**: 입점 승인 후 담당자가 발급합니다. 스스로 가입하는 화면은 없습니다.
- **상품 사진**: JPG·PNG·WEBP, 한 장당 5MB 이하. 첫 번째로 올린 사진이 대표 사진이 됩니다.
- **상품정보제공고시 내용**: 카테고리마다 필요한 항목이 다릅니다(예: 화장품은 용량·제조업자·사용기한·전성분·상담 전화번호).
  미리 준비해 두면 한 번에 끝낼 수 있습니다.
- **배송·반품 조건**: 배송비 방식(무료/조건부 무료/유료), 출고까지 걸리는 날, 반품 배송비, 반품 받을 주소는 검수 필수입니다.
- **옵션(색상·사이즈 등)**: 조합별 가격·재고가 다르면 미리 표로 정리해 두세요.
- **판매 권한이 필요한 카테고리**(화장품·식품 등): 인허가 서류로 판매 권한을 먼저 받아야 검수를 통과합니다.
- **생활용품**(주방·욕실·세탁청소)은 판매 권한 없이 등록할 수 있지만 고시 항목은 채워야 합니다. 세탁청소(세제·섬유유연제 등)는 「안전기준 적합확인 신고번호」와 「사용된 화학물질 명칭」이 필수입니다.
  서류는 담당자에게 제출합니다 — 파트너센터에는 서류 올리는 화면이 아직 없습니다.

## 3. 따라 하기

### 3-1. 로그인
1. <https://partner.posselect.com> 에 접속합니다 → 「파트너센터 로그인」 화면이 나옵니다.
2. 「아이디」와 「비밀번호」를 입력하고 「로그인」을 누릅니다 → 「내 상품」 목록으로 이동합니다.

### 3-2. 상품 등록(임시저장)
1. 상단의 「상품 등록」을 누릅니다.
2. **카테고리를 먼저 고릅니다.** 「대분류 선택」 → 「소분류 선택」 순서입니다.
   → 카테고리를 고르면 그 카테고리에 필요한 **상품정보제공고시** 안내와 입력칸이 아래에 나타납니다.
3. 「상품명」, 「판매가(원)」, 「재고」를 입력합니다. 「브랜드」, 「정가(원)」, 「상세 설명」은 해당하면 입력합니다.
   무료배송 여부는 여기가 아니라 아래 「판매 정책」의 「배송비」에서 정합니다.
4. 「상품 이미지」에서 파일을 골라 올립니다 → 올린 사진이 미리보기로 보입니다. 잘못 올린 사진은 사진 위 「✕」로 뺍니다.
5. 아래 「상품정보제공고시」 칸을 모두 채웁니다.
6. 「판매 정책」을 채웁니다(3-5 참고). 과세 구분·배송비·반품 배송비·반품·교환 주소는 검수 필수입니다.
7. 「임시저장」을 누릅니다 → 「임시저장했습니다. 검수를 받으려면 '검수 제출'을 눌러 주세요.」가 보이면 저장된 것입니다.
   이때부터 주소가 상품 번호가 붙은 주소로 바뀌어, 나중에 「내 상품」에서 다시 열 수 있습니다.

### 3-2-1. 옵션(색상·사이즈 등)이 있는 상품
옵션은 **한 번 임시저장한 뒤에** 설정할 수 있습니다(그 전에는 「옵션(색상·사이즈 등)은 임시저장한 뒤 설정할 수 있습니다.」가 보입니다).
1. 상품 화면 아래 「옵션 · SKU」에서 「옵션 이름 (예: 색상)」과 「값 (예: 블랙, 화이트)」을 입력합니다. 값은 쉼표로 구분합니다.
2. 옵션이 더 있으면 「옵션 종류 추가」를 눌러 최대 3개까지 넣습니다.
3. 「조합별 기본 가격(원)」과 「조합별 기본 재고」를 입력합니다 → 「만들어질 조합: N개 (최대 100개)」에 조합 수가 보입니다.
4. 「옵션 조합 만들기」를 누르고 「옵션 조합 N개가 만들어집니다. 옵션은 한 번 만들면 다시 구성할 수 없습니다. 계속할까요?」에서 확인합니다.
   → 「옵션·SKU 를 저장했습니다.」와 함께 조합별 표가 나타납니다.
5. 표에서 조합마다 「SKU 코드」(선택), 「가격(원)」, 「재고」, 「판매」(체크 해제 시 그 조합은 팔지 않음)를 고치고 그 줄의 「저장」을 누릅니다.
   옵션이 있는 상품은 위쪽 「판매가(원)」·「재고」 칸이 잠기고 「옵션이 있는 상품은 판매가·재고를 아래 옵션·SKU 표에서 조합별로 고칩니다.」가 보입니다.
   쇼핑몰에는 판매 중인 조합 중 가장 낮은 가격이 대표 가격으로 보입니다.

### 3-3. 검수 제출
1. 상품 화면에서 「검수 제출」을 누릅니다 → 입력 내용이 먼저 저장되고 제출됩니다.
2. 「제출했습니다. 자동 검사 결과를 기다리는 중...」이 보이고 보통 몇 초 안에 결과가 나옵니다.
   - 결과가 **「검수: 심사 중」**이면 자동 검사를 통과해 담당자 심사를 기다리는 상태입니다. 할 일은 없습니다.
   - 결과가 **「검수: 보완 필요」**이면 3-4 로 갑니다.
   - 「제출은 접수됐습니다. 자동 검사가 길어지고 있어 잠시 후 다시 확인해 주세요.」가 나오면 제출은 된 것입니다.
     잠시 뒤 「내 상품」에서 상태를 확인하세요.

### 3-4. 보완 요청을 받았을 때
1. 「내 상품」에서 상태가 「보완 필요」인 상품을 엽니다.
2. 고쳐야 할 내용이 **해당 입력칸 바로 아래**에 빨간 글씨로 표시됩니다(「보완 필요 · …」).
   특정 칸에 속하지 않는 내용(심사 담당자의 의견 등)은 **폼 맨 위**에 모여 있고, 「심사 의견: …」도 거기에 보입니다.
3. 표시된 칸을 고친 뒤 「보완 후 재제출」을 누릅니다 → 3-3 과 같은 순서로 다시 검사됩니다.

### 3-5. 판매 정책 입력
「판매 정책」 칸은 「임시저장」·「검수 제출」을 누를 때 함께 저장됩니다.
1. 「과세 구분」을 고릅니다(과세·면세·영세).
2. 「배송비」를 고릅니다 → 「유료배송」이면 「배송비(원)」, 「조건부 무료배송」이면 「배송비(원)」과 「무료배송 기준 금액(원)」 칸이 나타납니다. 「무료배송」이면 배송비 칸이 없습니다.
3. 「출고 소요일」(결제 후 출고까지 영업일), 제주·도서산간 추가 배송비를 입력합니다.
4. 「반품 배송비(편도, 원)」, 「교환 배송비(왕복, 원)」, 「반품·교환 주소」를 입력합니다.
5. 전기·생활용품, 어린이제품처럼 KC 인증 대상이면 「KC 인증」 유형을 고르고 「KC 인증번호」를 입력합니다.
6. 판매 기간이 정해져 있으면 「판매 시작」·「판매 종료」를, 한 번에 살 수 있는 수량을 제한하려면 「1회 최대 구매 수량」을 입력합니다. 비우면 제한이 없습니다.
   → 쇼핑몰에서 판매 기간이 아니거나 최대 수량을 넘으면 고객의 장바구니 담기·주문이 막힙니다(상품은 목록에 계속 보입니다).
배송비·출고 소요일·반품/교환 배송비·반품지·KC 인증은 쇼핑몰 상품 상세의 「배송·교환·반품 안내」에 그대로 공개됩니다.

## 4. 입력 항목 설명

| 항목 | 필수 | 설명 | 입력 규칙 |
|---|---|---|---|
| 카테고리 | 예 | 상품의 분류. 고시 항목이 카테고리에 따라 정해집니다 | 소분류가 있으면 소분류까지 선택 |
| 상품명 | 예 | 쇼핑몰에 보이는 이름 | 200자 이하. 「최고」「1위」「100% 보장」「국내 유일」「완치」는 쓸 수 없습니다(과장·허위 광고 방지) |

| 정가(원) | 아니오 | 할인 전 가격. 할인율 표시에 쓰입니다 | 비워 두거나, 판매가 이상 |

| 상세 설명 | 아니오 | | 비어 있으면 검수에서 참고 의견이 붙습니다. 위 금지 표현은 여기서도 참고 의견 대상 |

| 판매 시작·종료 | 아니오 | 판매 기간 | 종료가 시작보다 뒤. 비우면 제한 없음 |

| 상품정보제공고시 | 카테고리별 | 「전자상거래 등에서의 상품 등의 정보제공에 관한 고시」에 따라 구매 전에 알려야 하는 정보 | 표시된 칸은 모두 입력해야 검수를 통과합니다 |

## 5. 상태와 진행 흐름

「내 상품」 목록에는 **상품 상태**와 **검수 상태** 두 가지가 보입니다.

| 상품 상태 | 뜻 |
|---|---|
| 작성 중 | 아직 판매되지 않는 상품. 수정·제출할 수 있습니다 |
| 판매 중 | 승인되어 쇼핑몰에 노출 중. 이 화면에서는 수정할 수 없습니다 |
| 판매 중지 / 보관 | 노출되지 않는 상태. 변경은 담당자에게 문의 |

| 검수 상태 | 뜻 | 다음에 할 일 / 누가 |
|---|---|---|
| 미제출 | 아직 한 번도 제출하지 않음 | 파트너: 「검수 제출」 |
| 제출됨 · 자동 검사 중 | 자동 검사 진행 중(보통 몇 초) | 기다리기. 이 동안은 수정할 수 없습니다 |
| 보완 필요 | 자동 검사 또는 담당자가 수정을 요청 | 파트너: 표시된 칸을 고치고 「보완 후 재제출」 |
| 심사 중 | 자동 검사를 통과해 담당자 심사 대기 | 담당자: 승인 또는 보완 요청. 이 동안은 수정할 수 없습니다 |
| 승인 | 판매 시작. 상품 상태가 「판매 중」이 됩니다 | — |

## 6. 자주 보는 메시지와 해결 방법

| 화면 메시지(원문) | 원인 | 해결 |
|---|---|---|

## 7. 알아 둘 제한 사항

- **판매 중인 상품은 파트너센터에서 고칠 수 없습니다** — 판매 중인 상품의 가격·정보가 검수 없이 바뀌는 것을 막기 위해서입니다.
- **로그인 후 약 30분 동안 아무것도 하지 않으면 다시 로그인해야 합니다.** 긴 설명을 쓸 때는 중간에 「임시저장」을 누르세요.
  (보안 설정값 기준, 실제 시간 경과 동작은 미확인)
- 한 상품에 진행 중인 검수는 하나뿐입니다. 제출 버튼을 여러 번 눌러도 중복 제출되지 않습니다.
- 인허가 서류 제출 화면은 아직 없습니다. 필요하면 담당자에게 문의하세요.
- **옵션은 한 번 만들면 다시 구성할 수 없습니다** — 기존 조합을 지우면 재고 기록까지 지워지기 때문입니다. 잘못 만들었다면 담당자에게 문의하세요.
- 판매 기간 밖이거나 최대 수량을 넘는 구매는 막히지만, 상품은 쇼핑몰 목록·상세에 계속 보입니다.
- 일부 검수 메시지에 「SKU」 같은 내부 용어가 섞여 있습니다. 「SKU」는 판매 단위(옵션별 상품)를 뜻합니다.
